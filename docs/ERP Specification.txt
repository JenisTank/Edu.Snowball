4.	If no parent response by lock time + 2 hours — admin makes direct call to primary contact
s.	Call outcome logged in Leave Application tab

7.	3+ consecutive days absent without communication O Centre Head escalation — personal call to family

Key Design Decisions from Video Analysts
Default = Absent (Attendance) Saraswati defaults all students to Present. BumbleB flips this — default Absent, teacher actively marks Present. Prevents accidental all-present submission.
Child safety driven.
No Admin profile sharing (Users) Saraswati has 164 users all marked "Admin" — no role differentiation. BumbleB enforces 6 distinct roles from Day 1. Every person has own login. Shared accounts = DPDP violation.
Discipline	Child Support Log Saraswati's Discipline module: zero entries — pedagogically wrong for a preschool. BumbleB reframes as internal observation log. Support, not punishment. Never visible to parents.
No third-party LMS Saraswati embeds Butterfly Lab vendor inside ERP. BumbleB's AI layer is BuzzPortfolio + EduGrowth Matrix — both proprietary. No external LMS vendor integrated.
 
App-first parent communication Saraswati's parent comms are SMS-based and ad hoc. BumbleB's app is the primary channel post-familiarization, with WhatsApp as fallback. Every parent is trained at familiarization day to use the app — see Module 12 spec (companion file).
